# 简单 CRUD 网站

一个无需安装依赖的前端练习项目，支持：

- 新增记录
- 查看记录
- 编辑记录
- 删除记录
- 搜索记录
- 使用浏览器 `localStorage` 保存数据

## 运行

在项目目录执行：

```powershell
python -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 测试

```powershell
node --test test/store.test.mjs
```

本项目没有自动提交 Git。你可以在确认修改后自己执行：

```powershell
git add .
git commit -m "创建简单 CRUD 网站"
```
